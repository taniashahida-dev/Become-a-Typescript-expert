
# Problem Solving with TypeScript & OOP

This repository contains my solutions for the Programming Hero Next Level Batch 08 assignment on Problem Solving with TypeScript and Object-Oriented Programming (OOP).

## Assignment Overview

In this assignment, I practiced different TypeScript concepts and improved my problem-solving skills through practical coding tasks.

The assignment covers:

- Basic Types and Type Annotations
- Optional Parameters
- Union Types and Type Narrowing
- Readonly Tuples
- Generics and Rest Parameters
- Interfaces
- Keyof Constraints
- Object-Oriented Programming (OOP)
- Classes, Inheritance, and Access Modifiers
- Promises and Asynchronous Programming
